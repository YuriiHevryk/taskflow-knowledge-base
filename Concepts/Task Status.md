# Task Status

Task Status визначає поточний стан виконання [[Task]].

## Можливі значення

- Planned - завдання заплановане.
- In Progress - завдання виконується.
- Completed - завдання завершене.

## Використання

Користувач може змінювати статус завдання.

За статусами система фільтруватиме завдання та обчислюватиме статистику виконання.
