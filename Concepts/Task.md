# Task

Task - основна сутність застосунку TaskFlow, яка представляє окреме завдання користувача.

## Характеристики

- ID - унікальний ідентифікатор.
- Title - назва завдання.
- Description - опис.
- Priority - пріоритет виконання.
- Status - поточний стан.
- Due date - кінцевий термін виконання.

## Пов'язані поняття

- [[Task Status]]
- [[Task Priority]]

## Використання

Створення, редагування, видалення та перегляд завдань виконуватиметься через [[Task Service]].

Зберігання завдань забезпечуватиме [[Task Repository]].
