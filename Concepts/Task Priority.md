# Task Priority

Task Priority визначає важливість виконання [[Task]].

## Рівні пріоритету

- Low - низький.
- Medium - середній.
- High - високий.

## Використання

Пріоритет встановлюється користувачем під час створення або редагування завдання.

Система використовуватиме пріоритет для фільтрації та впорядкування завдань.
