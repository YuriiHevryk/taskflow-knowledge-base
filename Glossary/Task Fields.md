# Task Fields

Основні терміни, що використовуються для опису завдання в TaskFlow.

## Терміни

- ID - унікальний ідентифікатор завдання.
- Title - назва завдання.
- Description - текстовий опис завдання.
- Status - поточний стан виконання.
- Priority - рівень важливості завдання.
- Due Date - кінцевий термін виконання.
