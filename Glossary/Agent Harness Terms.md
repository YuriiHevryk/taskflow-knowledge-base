# Agent Harness Terms

Основні поняття інфраструктури Agent Harness.

## Терміни

- Agent Harness - інфраструктура для контрольованої роботи ШІ-агента.
- Knowledge Base - база знань про застосунок.
- Vault - сховище нотаток Obsidian.
- MCP - протокол підключення зовнішніх інструментів до агента.
- Skill - формалізована процедура виконання типової задачі.
- Guardrail - правило, яке обмежує дії агента.
- Hook - механізм перевірки дій агента під час виконання.
