# Правила оформлення нотаток TaskFlow

## Загальні правила

Усі нотатки зберігаються у форматі Markdown.

Кожна нотатка повинна містити YAML frontmatter з такими полями:
- type - тип нотатки.
- created - дата створення.
- tags - теги для класифікації.

Для зв'язків між нотатками використовуються wiki-посилання [[Назва нотатки]].

## 1. Шаблон поняття (Concepts)

```yaml
---
type: concept
created: 2026-11-08
tags:
  - taskflow
  - concept
---
```

Структура:
- Опис поняття.
- Основні характеристики.
- Пов'язані нотатки.

## 2. Шаблон компонента (Components)

```yaml
---
type: component
created: 2026-11-08
tags:
  - taskflow
  - component
---
```

Структура:
- Призначення компонента.
- Основні функції.
- Залежності від інших компонентів.

## 3. Шаблон рішення (Decisions)

```yaml
---
type: decision
created: 2026-11-08
status: accepted
tags:
  - taskflow
  - decision
---
```

Структура:
- Контекст.
- Прийняте рішення.
- Обґрунтування.
- Наслідки.

## 4. Шаблон глосарія (Glossary)

```yaml
---
type: glossary
created: 2026-11-08
tags:
  - taskflow
  - glossary
---
```

Структура:
- Термін.
- Визначення.
- Пов'язані поняття.

## 5. Правила найменування

Назви файлів використовують англійські терміни без скорочень.

Приклади:
- Task.md
- Task Status.md
- Task Service.md
- Task Repository.md

Посилання повинні точно відповідати назвам файлів.
