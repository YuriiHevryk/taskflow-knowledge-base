# SQLite Storage Decision

## Контекст

Застосунок TaskFlow повинен зберігати завдання між запусками програми. Для цього необхідне локальне сховище даних.

## Розглянуті варіанти

1. JSON - простий формат, але незручний для складніших операцій пошуку та оновлення.
2. SQLite - локальна реляційна база даних без окремого сервера.
3. PostgreSQL - повноцінна СУБД, що потребує додаткового налаштування.

## Прийняте рішення

Для збереження завдань обрано SQLite.

## Обґрунтування

SQLite не потребує окремого сервера, підтримує SQL-запити та входить до стандартної бібліотеки Python через модуль sqlite3.

Для невеликого локального застосунку її можливостей достатньо.
