# CLI

CLI - інтерфейс командного рядка застосунку TaskFlow.

## Основні функції

- Відображення меню користувача.
- Приймання команд.
- Виведення списку завдань.
- Відображення повідомлень про помилки.
- Передавання команд до Task Service.

## Призначення

CLI забезпечує взаємодію користувача із застосунком. Обробка завдань виконується окремим компонентом бізнес-логіки.
