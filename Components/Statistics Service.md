# Statistics Service

Statistics Service - компонент обчислення статистики завдань.

## Основні функції

- Підрахунок загальної кількості завдань.
- Підрахунок виконаних завдань.
- Підрахунок невиконаних завдань.
- Обчислення відсотка виконання.
- Формування зведеної статистики.

## Призначення

Компонент отримує інформацію про завдання через Task Repository та використовує її для обчислення статистичних показників.
